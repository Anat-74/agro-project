# Установка и настройка open-webSearch MCP-сервера

## Настройка MCP-сервера

Конфигурация MCP-сервера уже создана в файле `.kilocode/mcp.json`.

## Использование MCP-инструментов

После перезапуска VS Code, вы сможете использовать следующие инструменты в Kilo Code:

- `mcp_open___websearch___search` - Поиск в вебе через различные поисковые системы (DuckDuckGo, Bing, Baidu, Exa)

Эти инструменты позволят Kilo Code напрямую обращаться к интернету для получения актуальной информации без необходимости копировать ссылки вручную. Сервер использует несколько поисковых систем без необходимости в API-ключах.
