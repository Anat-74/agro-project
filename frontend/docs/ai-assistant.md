# AI Ассистент для Agro-Market проекта

## Обзор

AI-ассистент интегрирован в agro-market проект для помощи пользователям с:

- Поиском и рекомендацией продуктов
- Ответами на вопросы о доставке и оплате
- Помощью с корзиной покупок
- Консультацией по сельскохозяйственной продукции
- Ответами на вопросы о проекте

## Техническая архитектура

### Компоненты системы

1. **Frontend компонент**: `ChatAssistant.vue`
   - Плавающая кнопка чата
   - Модальное окно с историей сообщений
   - Быстрые предложения (quick suggestions)
   - Индикатор набора текста

2. **API endpoint**: `/api/chat-assistant`
   - Обработка сообщений пользователя
   - Интеграция с DeepSeek API
   - Управление сессиями через cookies
   - Поддержка MCP tools

3. **MCP Tools**:
   - `chat_assistant` - базовые операции ассистента
   - `strapi_products` - работа с продуктами из Strapi
   - `cart_operations` - управление корзиной покупок

4. **Интеграция с DeepSeek API**:
   - Модель: `deepseek-chat`
   - OpenAI-совместимый endpoint
   - Поддержка tool calls
   - Контекст: 128K токенов

## Настройка

### 1. Получение API ключа DeepSeek

1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com)
2. Создайте API ключ в личном кабинете
3. Добавьте ключ в `.env` файл:
   ```env
   DEEPSEEK_API_KEY=your_api_key_here
   ```

### 2. Конфигурация MCP

MCP Toolkit уже настроен в `nuxt.config.ts`. Проверьте настройки:

```typescript
// nuxt.config.ts
mcp: {
  // Auto-discovery of tools, prompts, resources
},
runtimeConfig: {
  mcp: {
    enabled: process.env.MCP_ENABLED === 'true' || true,
    debug: process.env.MCP_DEBUG === 'true' || false,
  },
}
```

### 3. Переменные окружения

Добавьте в `.env` файл:

```env
# DeepSeek API
DEEPSEEK_API_KEY=your_deepseek_api_key_here

# MCP настройки
MCP_ENABLED=true
MCP_DEBUG=false
```

## Использование

### Для пользователей

1. **Открытие чата**: Нажмите на плавающую кнопку "AI Ассистент" в правом нижнем углу
2. **Быстрые вопросы**: Используйте предложенные вопросы для быстрого старта
3. **Ввод сообщений**: Введите вопрос в текстовое поле и нажмите Enter или кнопку отправки
4. **История чата**: История сохраняется между сессиями (30 дней)

### Для разработчиков

#### Добавление новых инструментов

1. Создайте новый файл в `server/mcp/tools/`:

   ```typescript
   // server/mcp/tools/your-tool.ts
   import { defineMcpTool } from "@nuxtjs/mcp-toolkit/server";
   import { z } from "zod";

   export default defineMcpTool({
     name: "your_tool",
     description: "Описание вашего инструмента",
     inputSchema: z.object({
       // параметры
     }),
     execute: async ({ input, context }) => {
       // логика инструмента
       return { success: true, data: {} };
     },
   });
   ```

2. Добавьте инструмент в `AVAILABLE_TOOLS` в `chat-assistant.post.ts`

#### Кастомизация интерфейса

Компонент `ChatAssistant.vue` поддерживает:

- Изменение цветовой схемы через CSS переменные
- Настройку позиции кнопки
- Добавление новых быстрых предложений
- Интеграцию с системными уведомлениями

## Тестирование

### Локальное тестирование

1. Запустите dev сервер:

   ```bash
   npm run dev
   ```

2. Откройте браузер по адресу `http://localhost:3000`

3. Нажмите на кнопку AI ассистента

4. Проверьте:
   - Открытие/закрытие модального окна
   - Отправку сообщений
   - Получение ответов от API
   - Сохранение истории

### Тестирование без API ключа

Без действительного API ключа DeepSeek, ассистент будет возвращать ошибки. Для демонстрации можно использовать mock режим:

1. Создайте mock endpoint:

   ```typescript
   // server/api/chat-assistant-mock.post.ts
   export default defineEventHandler(() => {
     return {
       success: true,
       message:
         "Это mock ответ от AI ассистента. Для реальных ответов настройте DeepSeek API.",
       sessionId: "mock_session",
     };
   });
   ```

2. Обновите компонент для использования mock endpoint

## Безопасность

### Меры безопасности

1. **API ключи**: Хранятся только на сервере, не передаются клиенту
2. **Сессии**: Используются HTTP-only cookies
3. **Лимиты**: Ограничение истории до 20 сообщений
4. **Валидация**: Проверка входных данных на сервере

### Рекомендации для production

1. **Rate limiting**: Добавьте ограничение запросов на endpoint
2. **Мониторинг**: Отслеживайте использование API и ошибки
3. **Резервные ключи**: Используйте несколько API ключей для отказоустойчивости
4. **Логирование**: Ведите логи запросов (без конфиденциальных данных)

## Устранение неполадок

### Частые проблемы

1. **"API ключ не найден"**
   - Проверьте `.env` файл
   - Перезапустите сервер после изменения переменных окружения

2. **"Ошибка сети"**
   - Проверьте подключение к интернету
   - Убедитесь, что DeepSeek API доступен

3. **"История чата не сохраняется"**
   - Проверьте настройки cookies в браузере
   - Убедитесь, что не используется режим инкогнито

4. **"Инструменты не работают"**
   - Проверьте конфигурацию MCP Toolkit
   - Убедитесь, что tools правильно экспортированы

### Логирование

Для отладки включите debug режим:

```env
MCP_DEBUG=true
```

Логи будут выводиться в консоль сервера.
