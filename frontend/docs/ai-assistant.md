# AI Ассистент для Agro-Market проекта

## Обзор

AI-ассистент интегрирован в agro-market проект для помощи пользователям с:

- Поиском и рекомендацией продуктов
- Ответами на вопросы о доставке и оплате
- Помощью с корзиной покупок
- Консультацией по сельскохозяйственной продукции
- Ответами на вопросы о проекте

## Техническая архитектура

### Компоненты системы

1. **Frontend компонент**: `ChatAssistant.vue`
   - Плавающая кнопка чата
   - Модальное окно с историей сообщений
   - Быстрые предложения (quick suggestions)
   - Индикатор набора текста

2. **API endpoint**: `/api/chat-assistant`
   - Обработка сообщений пользователя
   - Интеграция с DeepSeek API
   - Управление сессиями через cookies

3. **Интеграция с DeepSeek API**:
   - Модель: `deepseek-chat`
   - OpenAI-совместимый endpoint
   - Поддержка tool calls
   - Контекст: 128K токенов

## Настройка

### 1. Получение API ключа DeepSeek

1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com)
2. Создайте API ключ в личном кабинете
3. Добавьте ключ в `.env` файл:
   ```env
   DEEPSEEK_API_KEY=your_api_key_here
   ```

### 3. Переменные окружения

Добавьте в `.env` файл:

```env
# DeepSeek API
DEEPSEEK_API_KEY=your_deepseek_api_key_here
```

## Использование

### Для пользователей

1. **Открытие чата**: Нажмите на плавающую кнопку "AI Ассистент" в правом нижнем углу
2. **Быстрые вопросы**: Используйте предложенные вопросы для быстрого старта
3. **Ввод сообщений**: Введите вопрос в текстовое поле и нажмите Enter или кнопку отправки
4. **История чата**: История сохраняется между сессиями (30 дней)

### Для разработчиков

#### Интеграция с внешними сервисами

AI-ассистент может быть расширен для интеграции с внешними сервисами через API endpoints.

#### Работа с корзиной

AI-ассистент интегрирован с системой корзины проекта, позволяя пользователям выполнять следующие действия через чат:

- **Добавление товаров в корзину** – ассистент использует инструмент `strapi_products` для поиска товаров и инструмент `cart` для управления корзиной
- **Удаление товаров из корзины** – удаление по идентификатору товара
- **Обновление количества товаров** – изменение количества товаров в корзине
- **Очистка корзины** – полное удаление всех товаров
- **Просмотр корзины** – отображение текущего состояния корзины

##### Техническая реализация

1. **Инструмент `strapi_products`**:
   - Возвращает список товаров из Strapi с поддержкой фильтрации и пагинации
   - Использует MCP сервер Strapi для доступа к данным
   - Поддерживает поиск по названию, категории, подкатегории

2. **Инструмент `cart`**:
   - Выполняет операции с корзиной (add, remove, update, clear, show)
   - Интегрируется с глобальным состоянием корзины через Pinia store
   - Возвращает клиентские инструкции (`clientInstruction`) для отображения кнопок действий

3. **Обработка клиентских инструкций**:
   - Компонент `ChatAssistant.vue` форматирует ответы с кнопками действий
   - Используется экранирование JSON для безопасной вставки в атрибуты `onclick`
   - Обработчик `handleCartAction` перенаправляет действия в корзину

##### Настройка доступа

Для работы с корзиной через Strapi API необходим токен доступа:

```env
STRAPI_API_TOKEN=your_strapi_api_token_here
```

Токен должен быть добавлен в заголовок `Authorization` запросов к Strapi. Ассистент автоматически использует этот токен при вызове инструмента `strapi_products`.

##### Примеры использования

1. **Запрос пользователя**: "Добавь яблоки в корзину"
2. **Действие ассистента**:
   - Поиск товара "яблоки" через `strapi_products`
   - Получение `documentId` товара
   - Вызов инструмента `cart` с операцией `add_to_cart`
   - Возврат ответа с кнопкой "Добавить в корзину"
3. **Действие пользователя**: Нажатие на кнопку добавляет товар в корзину

## Тестирование

### Локальное тестирование

1. Запустите dev сервер:

   ```bash
   npm run dev
   ```

2. Откройте браузер по адресу `http://localhost:3000`

3. Нажмите на кнопку AI ассистента

4. Проверьте:
   - Открытие/закрытие модального окна
   - Отправку сообщений
   - Получение ответов от API
   - Сохранение истории

### Тестирование без API ключа

Без действительного API ключа DeepSeek, ассистент будет возвращать ошибки. Для демонстрации можно использовать mock режим:

1. Создайте mock endpoint:

   ```typescript
   // server/api/chat-assistant-mock.post.ts
   export default defineEventHandler(() => {
     return {
       success: true,
       message:
         "Это mock ответ от AI ассистента. Для реальных ответов настройте DeepSeek API.",
       sessionId: "mock_session",
     };
   });
   ```

2. Обновите компонент для использования mock endpoint

## Безопасность

### Меры безопасности

1. **API ключи**: Хранятся только на сервере, не передаются клиенту
2. **Сессии**: Используются HTTP-only cookies
3. **Лимиты**: Ограничение истории до 20 сообщений
4. **Валидация**: Проверка входных данных на сервере

### Рекомендации для production

1. **Rate limiting**: Добавьте ограничение запросов на endpoint
2. **Мониторинг**: Отслеживайте использование API и ошибки
3. **Резервные ключи**: Используйте несколько API ключей для отказоустойчивости
4. **Логирование**: Ведите логи запросов (без конфиденциальных данных)

## Устранение неполадок

### Частые проблемы

1. **"API ключ не найден"**
   - Проверьте `.env` файл
   - Перезапустите сервер после изменения переменных окружения

2. **"Ошибка сети"**
   - Проверьте подключение к интернету
   - Убедитесь, что DeepSeek API доступен

3. **"История чата не сохраняется"**
   - Проверьте настройки cookies в браузере
   - Убедитесь, что не используется режим инкогнито

 4. **"Инструменты не работают"**
    - Проверьте конфигурацию MCP Toolkit
    - Убедитесь, что tools правильно экспортированы

 5. **"Ошибка 403 Forbidden при работе с корзиной"**
    - Убедитесь, что в `.env` файле установлен `STRAPI_API_TOKEN`
    - Проверьте, что токен имеет достаточные права доступа (роль Super Admin)
    - Убедитесь, что заголовок `Authorization` добавляется в запросах к Strapi
    - Проверьте доступность Strapi по адресу `http://127.0.0.1:1337`

### Логирование

Для отладки включите debug режим:

```env
MCP_DEBUG=true
```

Логи будут выводиться в консоль сервера.
