# Инструкция по автоматической генерации sitemap.xml с использованием nuxt-cron

## Обзор

Для решения проблемы с доступом к API-эндпоинту на хостинге была реализована система автоматической генерации sitemap.xml с использованием модуля nuxt-cron. Это позволяет запускать задачу генерации карты сайта по расписанию внутри Nuxt-приложения, что решает проблему с переменными окружения и доступом извне.

## Архитектура решения

### 1. Модуль nuxt-cron

- Установлен как зависимость: `nuxt-cron`
- Настроен в `nuxt.config.ts` как один из модулей
- Задача запускается каждый час

### 2. Файлы системы

- `frontend/server/cron/generate-sitemap.ts` - cron-задача, запускающая генерацию sitemap
- `frontend/server/utils/generate-sitemap.ts` - основная функция генерации sitemap с использованием Nuxt runtime config
- `frontend/server/api/admin/generate-sitemap.post.ts` - API-эндпоинт для ручного запуска (теперь использует обновленную функцию)
- `frontend/scripts/generate-sitemap.ts` - CLI-скрипт, который теперь использует серверную функцию для совместимости

## Настройка

### 1. Установка зависимости

```bash
npm install nuxt-cron -D
```

### 2. Настройка в nuxt.config.ts

```typescript
modules: [
  // ... другие модули
  "nuxt-cron",
],
```

### 3. Переменные окружения

Убедитесь, что в файле `.env` или в настройках хостинга установлены следующие переменные:

```
SITE_URL=ваш_адрес_сайта
NUXT_PUBLIC_STRAPI_URL=адрес_вашего_strapi_api
NUXT_STRAPI_TOKEN=ваш_strapi_токен
```

## Использование

### 1. Автоматическая генерация

Карта сайта будет автоматически генерироваться каждый час. Файл sitemap.xml будет сохраняться в корневую директорию приложения.

### 2. Ручная генерация

Для ручной генерации карты сайта можно вызвать API-эндпоинт:

```bash
curl -X POST \
  -H "X-Sitemap-Token: ваш_токен" \
  https://ваш_сайт/api/admin/generate-sitemap
```

Где `ваш_токен` - это значение переменной окружения `SITEMAP_GENERATION_TOKEN`.

### 3. CLI-запуск

Для запуска генерации из командной строки:

```bash
cd frontend
npm run generate-sitemap
```

## Решение проблемы с переменными окружения

В новой реализации используется Nuxt runtime config для доступа к переменным окружения:

```typescript
const config = useRuntimeConfig()
const siteUrl = config.public.siteUrl || process.env.SITE_URL
const strapiUrl = config.public.strapi.url || process.env.NUXT_PUBLIC_STRAPI_URL
const strapiToken = config.strapi.token || process.env.NUXT_STRAPI_TOKEN
```

Это обеспечивает доступ к переменным окружения как в серверном, так и в клиентском контексте.

Функция генерации sitemap также загружает переменные окружения из .env файла с помощью функции loadEnv() в качестве резервного варианта, если runtime config недоступен.

## Проверка работоспособности

1. Убедитесь, что cron-задача запускается корректно, проверив логи приложения
2. Проверьте, что файл sitemap.xml создается и обновляется
3. Убедитесь, что API-эндпоинт по-прежнему работает при ручном вызове
4. Проверьте корректность сгенерированного sitemap.xml

## Устранение неполадок

Если cron-задача не запускается:

1. Проверьте, что приложение запущено и работает (cron-задачи работают только когда приложение запущено)
2. Проверьте логи приложения на наличие ошибок
3. Убедитесь, что все необходимые переменные окружения установлены
4. Проверьте, что модуль nuxt-cron корректно установлен и указан в настройках

Если возникают ошибки при генерации sitemap:

1. Проверьте доступность Strapi API
2. Убедитесь, что токен для доступа к Strapi действителен
3. Проверьте, что переменные окружения SITE_URL, NUXT_PUBLIC_STRAPI_URL и NUXT_STRAPI_TOKEN установлены корректно
