# Настройка cron-задач в Nuxt приложении

## Обзор

В этом проекте используется модуль `nuxt-cron` для автоматического выполнения задач по расписанию. Все cron-задачи находятся в директории `server/cron`.

## Установка и настройка

1. Установка модуля:
   ```bash
   npm install nuxt-cron -D
   ```

2. Добавление модуля в `nuxt.config.ts`:
   ```typescript
   export default defineNuxtConfig({
     modules: [
       // ... другие модули
       "nuxt-cron",
     ],
     cron: {
       runOnInit: false, // Не запускаем задачи при инициализации приложения
       timeZone: 'Europe/Moscow', // Указываем часовой пояс по умолчанию
       jobsDir: 'server/cron' // Директория для задач (по умолчанию)
     }
   })
   ```

## Существующие задачи

### 1. Генерация sitemap.xml

Файл: `server/cron/generate-sitemap.ts`

Запуск: Каждый час (`hourly`)

Описание: Автоматически генерирует sitemap.xml с учетом всех категорий, подкатегорий и продуктов из Strapi.

### 2. Очистка кэша изображений

Файл: `server/cron/cenerate-image-cache.ts`

Запуск: Каждый день (`daily`)

Описание: Удаляет файлы кэша изображений, старше 7 дней.

## Создание новых задач

Для создания новой cron-задачи:

1. Создайте файл в директории `server/cron` с расширением `.ts`
2. Используйте функцию `defineCronHandler`:
   ```typescript
   import { defineCronHandler } from '#nuxt/cron'
   
   export default defineCronHandler('everyMinute', async () => {
     console.log('Задача выполнена:', new Date().toISOString())
   }, {
     runOnInit: false,
     timeZone: 'Europe/Moscow'
   })
   ```

3. Доступные пресеты времени:
   - `everySecond` - каждую секунду
   - `everyMinute` - каждую минуту
   - `hourly` - каждый час
   - `daily` - каждый день
   - `weekly` - каждую неделю
   - `monthly` - каждый месяц
   - `yearly` - каждый год

## Тестирование задач

Для тестирования cron-задач можно использовать API-эндпоинты или CLI-скрипты:

1. Ручной запуск через API:
   ```bash
   curl -X POST http://localhost:3000/api/admin/generate-sitemap \
     -H "X-Sitemap-Token: ваш_токен"
   ```

2. Ручной запуск через CLI:
   ```bash
   cd frontend
   npm run generate-sitemap
   ```

## Мониторинг

Логи выполнения cron-задач можно найти в логах приложения. При возникновении ошибок они будут записаны в stderr.

## Устранение неполадок

1. Если задачи не запускаются:
   - Проверьте, что приложение запущено
   - Убедитесь, что модуль `nuxt-cron` правильно установлен
   - Проверьте логи приложения на наличие ошибок

2. Если задачи выполняются с ошибками:
   - Проверьте параметры задачи (время запуска, часовой пояс)
   - Убедитесь, что все зависимости установлены
   - Проверьте, что у задачи есть необходимые права доступа
