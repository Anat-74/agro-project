# Настройка автоматического обновления sitemap.xml через cron

## Подготовка

1. Убедитесь, что на сервере установлены:
   - Node.js
   - npm
   - Git (если проект клонируется с репозитория)

## Установка cron-задачи

### 1. Откройте crontab для редактирования:
```bash
crontab -e
```

### 2. Добавьте одну из следующих строк в зависимости от желаемой частоты обновления:

**Для обновления каждые 4 часа:**
```bash
0 */4 * * * cd /path/to/your/project/frontend && npm run generate-sitemap >> /path/to/your/project/frontend/logs/sitemap-cron.log 2>&1
```

**Для обновления раз в 6 часов:**
```bash
0 */6 * * * cd /path/to/your/project/frontend && npm run generate-sitemap >> /path/to/your/project/frontend/logs/sitemap-cron.log 2>&1
```

**Для обновления раз в 12 часов (утром и вечером):**
```bash
0 6,18 * * * cd /path/to/your/project/frontend && npm run generate-sitemap >> /path/to/your/project/frontend/logs/sitemap-cron.log 2>&1
```

**Для обновления раз в день в 2 часа ночи:**
```bash
0 2 * * * cd /path/to/your/project/frontend && npm run generate-sitemap >> /path/to/your/project/frontend/logs/sitemap-cron.log 2>&1
```

### 3. Использование подготовленного скрипта (рекомендуется)

Вместо прямого вызова npm-команды можно использовать подготовленный скрипт:

```bash
0 */4 * * * /path/to/your/project/frontend/scripts/cron-sitemap.sh
```

## Проверка работоспособности

### 1. Проверьте, что crontab содержит нужную задачу:
```bash
crontab -l
```

### 2. Проверьте логи выполнения:
```bash
tail -f /path/to/your/project/frontend/logs/sitemap-cron.log
```

### 3. Протестиуйте выполнение скрипта вручную:
```bash
cd /path/to/your/project/frontend && npm run generate-sitemap
```

## Параметры cron

Формат cron-задания: `минута час день_месяца месяц день_недели команда`

- `*` - любое значение
- `*/n` - каждые n единиц
- `a,b,c` - конкретные значения
- `a-b` - диапазон значений

## Примеры частот обновления

| Частота | Выражение cron | Описание |
|---------|----------------|----------|
| Каждый час | `0 * * * *` | В начале каждого часа |
| Каждые 2 часа | `0 */2 * *` | Каждые 2 часа |
| Раз в день в 3 утра | `0 3 * * *` | Ежедневно в 3:00 |
| Раз в неделю в понедельник в 2 утра | `0 2 * * 1` | Каждый понедельник в 2:00 |
| Раз в месяц в 1-е число в 4 утра | `0 4 1 * *` | Первого числа каждого месяца в 4:00 |

## Важные замечания

1. Убедитесь, что путь к проекту указан правильно
2. Убедитесь, что у пользователя, от имени которого запускается cron, есть доступ к файлам проекта
3. Проверьте, что Node.js и npm доступны в PATH для cron-пользователя
4. Рекомендуется настроить логирование для отслеживания выполнения задачи
5. Убедитесь, что .env файл содержит все необходимые переменные окружения

## Устранение неполадок

Если cron-задача не работает:

1. Проверьте, что PATH в crontab включает путь к Node.js:
   ```bash
   # В начале crontab файла добавьте:
   PATH=/usr/local/bin:/usr/bin:/bin
   ```

2. Проверьте логи системы:
   ```bash
   grep CRON /var/log/syslog
   ```

3. Используйте абсолютные пути ко всем исполняемым файлам:
   ```bash
   0 */4 * * * /usr/bin/node /path/to/your/project/node_modules/.bin/npm run generate-sitemap
