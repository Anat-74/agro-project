# SmartBackground Component

Компонент для отображения фоновых изображений с поддержкой современных форматов (AVIF, WebP) и плавной анимацией загрузки.

## Особенности

- Поддержка современных форматов изображений: AVIF, WebP
- Автоматический fallback к WebP для браузеров, которые не поддерживают AVIF
- Плавная анимация загрузки с эффектом размытия
- Опциональная предзагрузка AVIF-изображений для улучшения пользовательского опыта
- Полная поддержка CSS `image-set()` для адаптивных изображений
- Поддержка изображений из Strapi CMS

## Использование

### Простое использование:

```vue
<SmartBackground name="hero" />
```

### С кастомным путем:

```vue
<SmartBackground name="background" path="/images/custom" />
```

### Без анимации:

```vue
<SmartBackground name="hero" :preload="false" />
```

### Изображение из Strapi:

```vue
<SmartBackground name="background" :fromStrapi="true" />
```

## Параметры (Props)

| Имя        | Тип     | По умолчанию | Описание                                             |
| ---------- | ------- | ------------ | ---------------------------------------------------- |
| name       | string  | -            | (обязательный) Имя файла изображения без расширения  |
| path       | string  | "/images"    | Путь к папке с изображениями                         |
| preload    | boolean | true         | Включить/выключить предзагрузку AVIF и анимацию      |
| fromStrapi | boolean | false        | Использовать URL-адрес Strapi для изображений из CMS |

## События (Emits)

| Имя    | Параметры | Описание                                                         |
| ------ | --------- | ---------------------------------------------------------------- |
| loaded | -         | Срабатывает при загрузке AVIF-изображения (если preload включен) |

## Логика работы

1. При `preload="true"`:

   - CSS: Устанавливает WebP как fallback → AVIF (если поддерживается)
   - JS: Предзагружает AVIF → при загрузке добавляет класс `loaded` → включает анимацию
   - Если AVIF не загрузится:
     - У большинства пользователей: AVIF загрузится → сработает @load → появится с blur-эффектом
     - У некоторых пользователей: AVIF не загрузится (браузер не поддерживает) → WebP загрузится через CSS → изображение будет видно (просто без blur-анимации)

2. При `preload="false"`:
   - Изображение отображается сразу без анимации перехода
   - Используется тот же порядок fallback: WebP → AVIF

## Результат

- `preload="true"`: Большинство пользователей получают красивую анимацию появления, остальные - немедленный показ без анимации
- `preload="false"`: Немедленный показ без анимации (для случаев, когда анимация не нужна)
