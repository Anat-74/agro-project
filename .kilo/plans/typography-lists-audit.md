# Аудит типографики списков (`li`) и наследования от body

Статус: **запланировано, не начато.** Выполнять в непиковые часы (правка сквозная, затрагивает весь UI).

## Задача

1. Вернуть `body` → `@include adaptiveValue("font-size", 16, 14)` в `base/_globals.scss`.
2. Добавить глобально `li` → `@include adaptiveValue("font-size", 16, 15)`.
3. Убрать собственные `font-size` у детей списков, чтобы они наследовали от `li`.
4. Пройтись по остальным спискам проекта и проверить, где размер задан на `ul`/родителе.

## Почему так

Сейчас в фильтре у почти каждого текста свой размер (`toEm`/`toRem`/`adaptiveValue`), поэтому
изменение `body` на них не влияет (кроме подписей категорий — визуально). Централизация:
`li` задаёт размер списка, дети наследуют.

## Риски (проверить при аудите)

- `font-size` на `li` — **прямое** правило: сильнее наследования от `ul`. Любой список, который сейчас
  берёт размер с `ul`/контейнера (`.nav { font-size: 14px }`, футер, меню, карточки, корзина), станет 15px.
  Нужно найти все такие места; правила на самом `li`/классе перебивают глобальное.
- `UInput` задаёт размеры лейблов сам: `.u-input__radio-label` → `toRem(15)`,
  `.u-input__checkbox-label` → `toRem(14)`. Для фильтра нужен `font-size: inherit` через `:deep`.
- `toEm` — относительный (меняется на доли px при body 14→15), `toRem`/`adaptiveValue` — фиксированные.

## Известные явные размеры в фильтре (убрать/унаследовать)

| Элемент | Сейчас |
|---|---|
| Категории (radio-label) | `toRem(15)` в `UInput` |
| Теги (checkbox-label) | `toRem(14)` в `UInput` |
| Чипы цены (`button`) | `toEm(13)` |
| Счётчики категорий (`span`) | `toEm(14)` |
| «Введите цену» | `toEm(13)` |
| Поля цены | `toEm(15)` |
| Summary блоков | `toEm(18)` — решение: оставить крупнее или привязать к `adaptiveValue` |

## Чек-лист аудита `ul` vs `li`

Пройти: `AppHeader`/`BaseNavigation`, `AppFooter`/`NavigationFooter`, `ShowHamburger`/`HamburgerCatalog`,
`ProductCard`, `CartShopping`, `cabinet`, `blog`/`news`, `posadka-i-urozhay`, `zagotovki`, `CalcPage`,
`ShowShopFilter`. Для каждого списка: где задан `font-size` (ul / li / ребёнок) и что изменится.
