# План работ — Agro Market

## 🚫 Режим удалённой работы

> Если диалог идёт **удалённо** (не за компьютером) — **никаких установок и обновлений**.
> `npm install`, `nuxi module add`, `nuxt upgrade` и любые другие долгие операции — **только когда пользователь за ПК**.
> Причина: длинные/многословные команды сбрасывают snapshot и прерывают диалог.

## ⚠️ Ключевое правило работы

> **НИКАКИХ ДЕЙСТВИЙ без прямого утверждения пользователем.**
> Перед каждым шагом — получить одобрение.
> После каждого действия — обязательный отчёт/обратная связь.
> **Никаких `git push` без явного разрешения пользователя.**
> **Никакого запуска скриптов/команд без явного разрешения пользователя.**
> Если в процессе выполнения возникает проблема — **сразу сообщить и спросить как действовать**, а не пытаться угадать или мудрить самому.
> При нехватке информации (селектор, URL, структура UI) — **обратиться к пользователю**, а не придумывать 5 вариантов решения вслепую.

# Стандарты стилизации проекта Agro-Market

## 1. Глобальная конфигурация SCSS

Все SCSS-файлы подключаются глобально через `vite.css.preprocessorOptions.scss.additionalData`. В компонентах НЕ требуется `@use`:

```
Порядок загрузки:
1. @use "@/assets/scss/base/_settings.scss" as *;    // Брейкпоинты, контейнер
2. @use "@/assets/scss/base/_fonts.scss" as *;       // Шрифты
3. @use "@/assets/scss/base/_functions.scss" as *;   // Функции (toRem, toEm)
4. @use "@/assets/scss/base/_globals.scss" as *;     // Глобальные стили
5. @use "@/assets/scss/base/_utils.scss" as *;       // Утилиты
6. @use "@/assets/scss/base/_mixins.scss" as *;      // Миксины
7. @use "@/assets/scss/base/_normalize.scss" as *;   // Нормализация
```

---

## 2. Функции

### `toRem($px)` — перевод px в rem
```scss
$result: math.div($px, 16) + rem;
```
Используется ВМЕСТО всех px. Пример: `padding: toRem(16)` → `1rem`.

### `toEm($px, $current: 16)` — перевод px в em
Используется для брейкпоинтов. Пример: `font-size: toEm(15)` → `0.9375em`.

---

## 3. Миксины

**ВАЖНО: Все `@include` — строго ПОСЛЕ всех CSS-свойств**, перед вложенными селекторами.

### `@include adaptiveValue(property, startSize, minSize)`
Плавное изменение через `clamp()` при изменении вьюпорта. Всегда в конце свойств:

```scss
.selector {
  font-weight: 600;
  color: var(--color);
  @include adaptiveValue("font-size", 16, 14);  // ← в конце
}
```

### `@include hover`
Заменяет прямой `:hover`. Генерирует `@media (any-hover: hover) { &:hover { ... } }`. НЕ использовать `:hover` напрямую.

### `@include containerParent(name, type)`
Container Query parent: `@include containerParent(card, inline-size)`.

### `@include gridCards(type, min, max)`
Responsive grid: `@include gridCards(fit, toRem(260), 1fr)`.

## 6. BEM-нотация

```scss
.block                  // компонент
.block__element         // дочерний элемент
.block--modifier        // модификатор
.block__element--modifier
```

Правила:
- Корневой класс = имя блока (kebab-case)
- Элементы через `__`, модификаторы через `--`
- Один уровень вложенности
- Модификаторы через `&--modifier`

---

## 7. Порядок в SCSS-селекторе

```scss
.selector {
  // 1. CSS-свойства
  padding: toRem(12);
  color: var(--color);

  // 2. @include adaptiveValue — ПОСЛЕ всех свойств
  @include adaptiveValue("font-size", 16, 14);

  // 3. @include hover
  @include hover { color: var(--success-color); }

  // 4. Псевдоклассы
  &:focus { border-color: var(--success-color); }

  // 5. Модификаторы
  &--modifier { ... }
}
```

## 9. Grid Layout

### Grid Template Areas
```scss
display: grid;
grid-template-rows: auto 1fr auto;
grid-template-areas: "header" "body" "footer";
> * { min-width: 0; }
```

### Subgrid
```scss
.parent { grid-template-columns: auto 1fr; }
.child {
  grid-template-columns: subgrid;
  grid-column: 1 / -1;
}
```

### Container Query
```scss
@include containerParent(card, inline-size);
@container card (max-width: toRem(260)) {
  .card { grid-template-columns: 1fr; }
}
```



## 10. @container style() — стилевые запросы

Используется для применения стилей в зависимости от CSS-переменных на родительском контейнере.

### Синтаксис

`scss
// Внутри класса (рекомендуется — SCSS-вложенность)
.block {
  &__element {
    @container style(--theme: custom) {
      animation: cardEntrance 0.4s ease forwards;
    }
  }
}
`

### Доступные переменные

| Переменная | Источник | Назначение |
|-----------|----------|-----------|
| --theme | colorMode.preference | Анимации только для custom-темы |
| --brightness | useThemeBrightness | Тонирование через colorMix() миксин |
| --locale | useLocale().currentLocale | Типографика под язык |

### Когда использовать

| Случай | Использовать |
|--------|-------------|
| Анимации в определённой теме | @container style(--theme: custom) |
| Разная типографика для локалей | @container style(--locale: be) |
| Браузерные фиксы | @container style(--browser-safari: 1) |

### Когда НЕ использовать

- Для яркости фона — использовать миксин colorMix()
- Для адаптива — @media / @container (inline-size)
- Для детекта возможностей — @supports

### Поддержка браузеров

@container style() поддерживается в 88%+ браузеров (Chrome 125+, Firefox 135+, Safari 18+).

## 12. Правила (из чата)

1. **`toRem()`** — 0 px
2. **`var(--*)`** — 0 хардкоженных цветов
3. **`@include hover`** — 0 прямых `:hover`
4. **`$mobile`/`$tablet`** — 0 хардкоженных брейкпоинтов
5. **Миксины — после CSS-свойств**
6. **BEM** — 0 не-BEM селекторов
7. **`<header>`/`<main>`/`<footer>`** — вместо `<div>`
8. **`> * { min-width: 0 }`** — на grid-родителях
9. **`order`** — для перестановки в grid
10. **`<UButton>`** — вместо `<button>`
11. **Типы из shared** — не дублировать
