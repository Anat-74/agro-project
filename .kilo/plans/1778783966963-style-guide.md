> Если диалог идёт **удалённо** (не за компьютером) — **никаких установок и обновлений**.

> Перед каждым шагом — получить одобрение.
> После каждого действия — обязательный отчёт/обратная связь.
> **Никаких `git push` без явного разрешения пользователя.**
> **Никакого запуска скриптов/команд без явного разрешения пользователя.**
> Если в процессе выполнения возникает проблема — **сразу сообщить и спросить как действовать**, а не пытаться угадать или мудрить самому.
> При нехватке информации (селектор, URL, структура UI) — **обратиться к пользователю**, а не придумывать 5 вариантов решения вслепую.

# Стандарты стилизации проекта Agro-Market

## 1. Стек и принципы

- **Стек:** Nuxt 4, Vue 3, TypeScript, SCSS, BEM, Strapi v5.
- **Современный CSS-стек — только фичи с базовой поддержкой:** `<dialog>`, `@container` (inline-size), `@container style()`, `subgrid`, `:has()`, anchor positioning, `popover`, `@starting-style`, `:where()`. Bleeding-edge (anchor Level 2, `@container anchored`) — **не использовать**.
- **Минимум JS:** показ/скрытие, позиционирование, закрытие по Escape/клику вне, адаптив — решать нативными HTML/CSS-средствами (popover, dialog, `:has`, details), а не слушателями и `getBoundingClientRect()`.
- **Минимум обёрток (`div`):** grid + `:has()` + container queries позволяют в большинстве случаев позиционировать без лишних обёрток. Не оборачивать без необходимости. Семантические теги (`header`, `main`, `footer`, `section`, `nav`) — вместо `div`.
- **Данные:** из Strapi через `useAsyncData`/`useFetch`. Клиентские запросы — `server: false`; некритичные — `lazy: true`.

## 2. SCSS-подключение

Глобально через `vite.css.preprocessorOptions.scss.additionalData` (`nuxt.config.ts`) подключаются ТОЛЬКО `foundation/*` — в компонентах они доступны без `@use`:

```scss
@use "@/assets/scss/foundation/_settings.scss" as *;   // брейкпоинты, контейнер
@use "@/assets/scss/foundation/_functions.scss" as *;  // toRem, toEm
@use "@/assets/scss/foundation/_mixins.scss" as *;     // миксины
```

`base/*` (`_normalize.scss`, `_globals.scss`, `_utils.scss`, `_animations.scss`) подключаются один раз через `styles.scss` (css-entry) — в компонентах не импортируются.

## 3. Функции

- `toRem($px)` — вместо px. `padding: toRem(16)`.
- `toEm($px, $current: 16)` — em-размеры, брейкпоинты.

## 4. Миксины (все `@include` — ПОСЛЕ CSS-свойств, перед вложенными селекторами)

- `adaptiveValue(property, startSize, minSize)` — clamp() по вьюпорту. `@include adaptiveValue("font-size", 16, 14);`
- `hover` — вместо прямого `:hover` (`@media (any-hover: hover)`). Прямой `:hover` не использовать.
- `containerParent(name, type)` — `container: name / inline-size`.
- `containerAdaptive(property, start, min)` — адаптив от ширины контейнера (cqw) с viewport-fallback.
- `gridCards(type, min, max, gap)` — `repeat(auto-fit, minmax(min, max))`.
- `colorMix($property, $base-color, $mix-color, $ratio)` — тонирование через `color-mix(in srgb, ...)`. `$ratio: null` (default) — доля от `--brightness`.

## 5. Утилиты показа/скрытия (_utils.scss)

Если подходит утилита — свой `@media`-блок НЕ писать.

| Класс | Действие |
|---|---|
| `hidden-tablet` | скрыть при `max-width: $tablet` |
| `hidden-mobile` | скрыть при `max-width: $mobile` |
| `hidden-mobilesmall` | скрыть при `max-width: $mobileSmall` |
| `visible-tablet` | виден только при `max-width: $tablet` |
| `visible-mobile` | виден только при `max-width: $mobile` |

## 6. Брейкпоинты (em)

| Переменная | Значение |
|---|---|
| `$pc` | `toEm(1430)` |
| `$tablet` | `toEm(1023.98)` |
| `$mobile` | `toEm(767.98)` |
| `$mobileSmall` | `toEm(479.98)` |

Хардкодить брейкпоинты нельзя — только переменные.

## 7. CSS-переменные (styles.scss)

**0 хардкоженных цветов** — все через `var(--*)`.

Ключевые: `--color`, `--bg`, `--primary-color`, `--secondary-color`, `--light-color`, `--dark-color`, `--border-color`, `--gray-color`, `--bg-product`, `--bg-navigation`, `--bg-footer`, `--active-color`, `--danger-color`, `--warning-color`, `--success-color`, `--green-color`, `--transition-duration`.

Темы: `.light-mode`, `.dark-mode`, `.custom-mode`. ВАЖНО: `.dark-mode { filter: brightness(95%) }` создаёт stacking context — ломает `fixed`/`absolute` внутри; на top-layer (`popover`/`dialog`) не влияет.

## 8. BEM

- `.block` → `.block__element` → `.block__element_modifier`
- kebab-case, один уровень вложенности, модификаторы через `&--modifier`

## 9. Порядок в SCSS-селекторе

1. CSS-свойства
2. `@include adaptiveValue(...)` — после свойств
3. `@include hover`
4. Псевдоклассы (`&:focus`, `&:focus-visible`)
5. Модификаторы

## 10. Grid + Container Queries

- Вёрстка преимущественно на CSS Grid (не flex-цепочки из обёрток).
- Сложные блоки (большой footer) — `grid-template-areas`.
- `> * { min-width: 0 }` — на grid-родителях.
- Subgrid: `grid-template-columns: subgrid`.
- Container Queries: `@include containerParent(name, inline-size)` + `@container name (max-width: ...)`. Адаптив от ширины БЛОКА — container queries, от вьюпорта — `@media`.

## 11. @container style() — стилевые запросы

Применение стилей от CSS-переменных на родителе:

- `style(--locale: be|ru)` — типографика под язык (h1–h4: be → Open Sans + letter-spacing)
- `style(--theme: custom)` — анимации только в custom-теме
- `style(--browser-safari: 1)` — браузерные фиксы

НЕ использовать для: яркости фона (`colorMix()`), адаптива (`@media`/`@container` inline-size), детекта возможностей (`@supports`).

## 12. Типы Strapi (shared/types)

Все типы Strapi — в `frontend/shared/types/`, авто-импортируются, не дублировать.

## 13. `<dialog>` — блокирующие модалки (паттерн `ShowModal*` / `Show*`)

- Папка `components/show-modal/`, импорт явный.
- `useDialog(id, dialogRef, { useShowMethod })`:

| `useShowMethod` | Метод | Поведение |
|---|---|---|
| `false` (default) | `showModal()` | нативный backdrop + `::backdrop`, Escape нативно, body-lock |
| `true` | `show()` | без backdrop, Escape вручную, body-lock НЕТ |

- Конвенция имён: `ShowModal*` — `showModal()`, `Show*` — `show()`.
- Close on backdrop: `if (e.target === storedElement) close()` → внутри `<dialog>` всегда items-обёртка (панель).
- Body-lock в `_globals.scss`: `body:has(.dialog-hamburger[open], ...)` → при добавлении нового диалога добавить его класс в этот селектор.
- Анимация: `@starting-style` + `transition` с `allow-discrete` на `display`/`overlay`; позиционирование через `translate`/`margin-inline-start`.
- Родитель управляет через `defineExpose({ open, close, isOpen })` + `useTemplateRef`.

## 14. Поповеры/меню/тултипы — Anchor Positioning + Popover API (стандарт)

**Применять для новых:** дропдауны у кнопки (MoreMenu), тултипы, поповеры у ссылок, меню с автопереворотом.
**НЕ применять:** модалки на весь экран/по центру (это `<dialog>`, раздел 13); обычная вёрстка в потоке.

```html
<UButton variant="plain" class="more-menu__trigger" popovertarget="menu">Меню</UButton>
<div popover id="menu" class="more-menu__dropdown">…</div>
```

```scss
.more-menu {
  &__trigger {
    anchor-name: --more-menu;              // якорю даём имя
  }

  &__dropdown {
    position: fixed;                       // popover = top-layer
    margin: 0;
    inset: auto;
    position-anchor: --more-menu;          // цель привязывается
    position-area: bottom span-right;      // сетка 3×3, + span-* для растягивания
    margin-block-start: toRem(4);
    position-try-fallbacks: flip-block;    // автопереворот при нехватке места
  }
}
```

- Триггер — `<UButton variant="plain" popovertarget="...">`, НЕ `<button>` (см. раздел 17, п.5); `variant="plain"` — плоская кнопка без заливки

- Popover API: открытие/закрытие кликом, Escape, кликом вне — **без JS**. `popover="manual"` — без авто-закрытия (hover-поповеры).
- Top-layer: не нужны `z-index` и борьба с `overflow: hidden` у родителей.
- Для не-popover элементов (в потоке): `position: absolute` + `position-area`.
- Кастомный переворот: `@position-try --name { ... }` + `position-try-fallbacks: --name`.
- Анимация: fade — `@starting-style` + `allow-discrete`; высота — `height: 0→auto` + `interpolate-size: allow-keywords` (наследуется; Chrome/Edge/Opera, в FF/Safari без анимации высоты — progressive enhancement). ВАЖНО: самому `[popover]` `display` задавать нельзя (перебьёт UA-скрытие `[popover]:not(:popover-open)`) — `height`-анимацию делать на ВНУТРЕННЕМ элементе (карточке), не на поповере
- Старые браузеры: прогрессивное улучшение — базовое absolute-позиционирование оставить, anchor добавлять поверх.

## 15. Normalize — что уже сброшено (в компонентах НЕ повторять)

Сбросы применяются к элементам С КЛАССОМ (`:where(sel):where([class])`) — элементы без класса сохраняют браузерные дефолты (важно для контента Strapi).

| Что | Уже сброшено |
|---|---|
| `*`, `*::before`, `*::after` | `box-sizing: border-box` |
| `ul[class]` | `padding-left: 0; list-style: none` |
| `ol[class]` | `padding-left: 0` (нумерация остаётся) |
| `h1–h6, p, ul, ol, dl[class]` | `margin-block: 0` |
| `body`, `blockquote/figure[class]` | `margin: 0` |
| `button[class]` | `padding: 0; border: none; background: transparent; cursor: pointer` |
| `input, textarea, select, button` | `font-family/font-size: inherit` |
| `dialog[class]` | `padding: 0; border: none` |
| `[popover][class]` | `padding: 0; border: none; background: transparent; color: inherit` (для якорных — `margin: 0; inset: auto` в компоненте) |
| `html` | `height: 100%; scrollbar-gutter: stable` |
| `body` | `min-height: 100%` |
| `svg *` | `fill/stroke: currentColor` |
| `prefers-reduced-motion` | анимации/переходы отключены |

## 16. Глобальные стили (_globals.scss)

- `body`: Roboto, `--color`/`--bg`, `adaptiveValue("font-size", 16, 14)`.
- Шрифты: Roboto (основной), Yellowtail (h1, italic), Open Sans (контент + локаль be).
- Заголовки: h1 — Yellowtail italic, `--warning-color`, 36→28; h2 26→20; h3 18→16; h4 16→14. Локали через `@container style(--locale)`.
- `a[class]` — `text-decoration: none`; `:focus-visible` — outline `--warning-color`.
- `.router-link-active` задан глобально (`cursor: default; pointer-events: none`) — не переопределять.
- Глобальный hover-эффект `li`/`ul` — осознанное исключение, отключается через `:not()`.
- Дизайн-эффекты конкретных блоков — в scoped-стили компонента, не глобально.

## 17. Правила проекта (свод)

1. `toRem()` вместо px; 0 хардкоженных цветов (`var(--*)`); 0 хардкоженных брейкпоинтов
2. `@include hover` вместо прямого `:hover`
3. Миксины — после CSS-свойств
4. BEM; семантические теги вместо `div`; минимум обёрток (grid + `:has()`)
5. `<UButton>` вместо `<button>`
6. Типы из `shared/types` — не дублировать
7. Новые поповеры/меню/тултипы — Popover API + Anchor Positioning; модалки — `<dialog>` + `useDialog`
8. Современный CSS-стек с базовой поддержкой; bleeding-edge не использовать
9. Уже сброшенное в normalize — не обнулять повторно (раздел 15)
10. Не дублировать `@media` там, где есть утилиты (`hidden-tablet` и т.п.)
11. `@container style()` — только для стилевых запросов от переменных; не для адаптива/фич-детекта
