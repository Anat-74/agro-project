# Refactoring Plan - Agro Market

## Workflow Rules
- After completing each task, provide a brief report of what was done.
- Continue to the next task ONLY after user approval.


## Project Context

### Tech Stack
- Nuxt 4.4.2 (Nitro 2.13.2, Vite 7.3.1, Vue 3.5.30)
- SCSS (BEM, no Tailwind)
- TypeScript (interface for props, type for unions)
- Pinia (cart, search) + persistedstate
- Strapi v5 (on Plesk hosting)
- Netlify SSR (preset: netlify, NODE_VERSION 20)

### Key Composables
- useDialog(id, ref?, options?) - native dialog management
- useLocale(), useStrapi(), useCartStore(), useSearchStore()
- useNotification(), useDebounce() (Phase 3)

### CSS Conventions
- toRem()/toEm(), var(--), @include hover
- BEM: single underscore (_active)
- mixins after properties
- grid: > * { min-width: 0 }

### RouteRules (commented in nuxt.config.ts)
- / -> /ru redirect, sitemap.xml -> static
- /ru/about etc -> prerender, /ru -> ISR 1800
- /ru/* -> ISR 3600, /ru/*/products/* etc -> SWR 600
- /ru/cartshopping -> ssr: false, /api/** -> SWR 60

### SCSS Bug (found in audit)
- 4 CSS-generating files in additionalData -> duplicates in every component
- Fix: move to styles.scss, keep only settings/functions/mixins in additionalData
