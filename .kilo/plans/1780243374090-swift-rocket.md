### CRITICAL: Strapi v5 API Patterns (discovered in bug fixes)

**1. locale — всегда внутри filters с $eq:**
```ts
find("products", {
  filters: {
    slug: { $eq: productSlug },
    locale: { $eq: currentLocale.value },  // ✅ внутри filters
  },
} as any)
```
Никогда не ставить `locale` на верхнем уровне — `@nuxtjs/strapi` теряет этот параметр.

**2. deep filters — только nested-синтаксис (dot notation не работает с @nuxtjs/strapi):**
```ts
filters: { category: { slug: { $eq: categorySlug } } }      // ✅ nested object
// ❌ "category.slug" — модуль сериализует как filters[category.slug][$eq] — 400 Bad Request
```

**3. populate для компонентов — без id:**
```ts
seo: { fields: ["metaTitle", "metaDescription", "structuredData"] }  // ✅
// ❌ НЕ:["id", "title", "description"]
```

**4. sort — только массивом:**
```ts
sort: [sortOption.value]  // ✅ массив
// ❌ НЕ: sort: sortOption.value  (строка → 400)
```

**5. as any обязательно** — для всех `find` с generic типом:
```ts
find<Product>("products", { ... } as any)
```

**6. getProductLink требует populated category/subcategory:**
```ts
populate: {
  category: { fields: ["slug"] },
  subcategory: { fields: ["slug"], populate: { category: { fields: ["slug"] } } },
}
```

**7. fields — избегать id для полей не-collection типа:**
Для media и components `id` не валиден. Только: `alternativeText`, `url`, `name`, `slug`, `metaTitle`, `metaDescription` и т.д.

### Lazy fetch — только по клику

```ts
const dialogRef = useTemplateRef<HTMLDialogElement>("discount-dialog")
const { open, close, isOpen } = useDialog(
  `discount-product-${product.documentId}`,
  dialogRef,
  { useShowMethod: false }   // showModal
)

const { data: details, status, execute } = useAsyncData(
  `product-details-${product.documentId}`,           // статический ключ
  async () => {
    const { find } = useStrapi()
    return find(`products/${product.documentId}`, {
      populate: {
        images: { fields: ["url", "alternativeText"] },
      },
    } as any)
  },
  { immediate: false, server: false,                 // лениво
    getCachedData: (key) => details.value || null,  // кэш при повторном открытии
  }
)

const openModal = () => {
  open()
  if (!details.value) execute()                      // guard — не статус
}
```

- Статический ключ, не computed (documentId не меняется)
- `as any` — обязательно (Strapi v5 типы)
- Компоненты `UButton`, `UImage` — проектные

### Сейчас (проблемы)

**Данные грузятся при монтировании:**
```ts
useAsyncData(`category-dialog-${currentLocale.value}`, async () => {
```

- Продукты в категориях (строка ~194) — нет `close()`
- Подкатегории (раскомментированный код) — нет `close()`

**createError(404) при пустом списке:**
```ts
if (!response.data || response.data.length === 0) {
  throw createError({ statusCode: 404, ... })  // → страница 404
}
```
→ Нужно вернуть `[]` и обработать пустой список локально

### Исправления

#### 1. Lazy loading + computed key

```ts
const categoryKey = computed(() => `category-dialog-${currentLocale.value}`)

const { data: category, execute: executeCategory, refresh: refreshCategory } = useAsyncData(
  categoryKey,
  async () => {
    const response = await find<Category>("categories", {
      filters: { locale: { $eq: currentLocale.value } },
      populate: { image: { fields: ["alternativeText", "url"] },
                  subcategories: { fields: ["id", "name", "slug"] },
                  products: { fields: ["id", "name", "slug"],
                    populate: { image: { fields: ["alternativeText", "url"] },
                                category: { fields: ["slug"] },
                                subcategory: { fields: ["slug"],
                                  populate: { category: { fields: ["slug"] } } } } } },
    } as any)
    return response.data || []
  },
  { watch: [categoryKey], immediate: false, server: false, lazy: true }
)

// Обработчик открытия диалога
const open = () => {
  dialogElement.value?.show()
  if (!category.value) executeCategory()
  if (!product.value) executeProduct()
}
```

→ `watch(currentLocale, ...)` больше не нужен — `categoryKey` реактивный.

#### 2. @click="close()" на все NuxtLink

```html
<!-- Продукты в категориях -->
<NuxtLink class="accordion__product-link" :to="getProductLink(prod)"
  @click="close()">   <!-- добавить -->
</NuxtLink>

<!-- Подкатегории (раскомментированный код) -->
<NuxtLink @click="close()" :to="`/${currentLocale}/${cat.slug}/${sub.slug}`">
  {{ sub.name }}
</NuxtLink>
```

#### 3. Error handling (вместо createError)

```ts
if (!response.data || response.data.length === 0) {
  return []     // не throw createError(404)

return response.data
```

В шаблоне:
```html

  {{ showHamburgerT.empty }}

```

#### 4. Обработка ошибок для products отдельно

Сейчас из `useAsyncData` для products деструктуризированы `data`, `pending`, `refresh` — нет `error`.
Добавить `error: productError` в деструктуризацию и показывать отдельно:
