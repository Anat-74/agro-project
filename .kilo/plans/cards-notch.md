# Карточка товара: вырез под «в корзину» — текущая задача

Обновлено: 26.10.2026. Читать в начале сессии вместе с `frontend/docs/style/patterns.md` (§7–§9).

## Текущее состояние
- Вырез (CSS-маска inverted-radius) включён **только в компактном режиме** (`product-card_compact`, фильтр закрыт) — там нет 3D-переворота.
- На главной и при открытом фильтре выреза **нет** — карточка переворачивается, маска тормозит при rotateY.
- Кнопка «в корзину»: `position: absolute`, `right/bottom: calc(зазор − 5px)`, форма — исходный `add` (radius 6).
- Галочка в корзине: исходная геометрия (`.btn_add_is-added`: -58°/60°, right-based), восстановлена коммитом 8177574.
- Пиксельный замер (magenta + sharp): **справа/снизу — 6–8px, сверху/слева — 0**. `s` не управляет верх/лево (проверено 26/44/54).

## Грабли (не повторять)
- `translateZ(0)`/промоут слоя **ломает отрисовку маски** (вырез пропадает) — откатано.
- `.product-card_geo1…5` (демо) перекрывал `--notch-*` и «съедал» новые значения — удалён.
- Замена варианта `add` без перечисления состояний → потерян `btn_add_is-added` (галочка).
- DOM-прямоугольники для маски не показательны — только пиксели.

## Что осталось
1. **Кнопку «в корзину» вернуть в поток**: вынести нижний ряд `__bottom-items` (цена + кнопка) за пределы маскированной поверхности; сейчас ряд без кнопки, кнопка absolute.
2. **Горизонтальный скролл**: `window.innerWidth 1034` vs `clientWidth 1019` = 15px скроллбара; элементов за краем нет → виноват `100vw`. Заменить те `100vw`, что задают ширину блока, на `100%`/`100dvw`.
3. **SVG clipPath на тестовой карточке** (`ir-demo`): рядом CSS-маска и SVG `clip-path: path(...)`; path генерировать из параметров (ширина, высота, радиус, вырез, скругление); сравнить форму/зазоры/цену.
4. После SVG-сравнения — решить, переносить ли вырез на path (там же проверить, уходит ли задержка при 3D).
