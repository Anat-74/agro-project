# План: Быстрые предложения (quick suggestions) в AI-ассистенте

## Проблема

В чате AI-ассистента при открытии отображается пустое окно без стартовых подсказок. Существующий компонент уже рендерит кнопки `suggestion-button` в `.empty-state`, но массив `quickSuggestions` пуст (`const quickSuggestions: string[] = []`).

## Решение

Загружать `quickSuggestions` из Strapi singleType `ai-assistant` и обновить их содержимое на агро-тематику.

### Шаг 2: Загружать подсказки из Strapi в ChatAssistant.vue

**Файл:** `frontend/app/components/chat-assistant/ChatAssistant.vue`

**Изменения:**

1. В `onMounted` добавить fetch к Strapi для получения `quickSuggestions`:
```typescript
const loadQuickSuggestions = async () => {
  try {
    const response = await $fetch('/api/products', {
      baseURL: 'http://127.0.0.1:1337',
      params: {
        'filters[documentId][$eq]': 'berer6bv06y6ttwy5gdy29tq'
      }
    })
    // Неверный эндпоинт — нужен правильный
  } catch {
    // fallback тихо
  }
}
```

На самом деле, правильнее сделать простой API endpoint внутри проекта (а не прямой запрос к Strapi из клиента, чтобы не светить URL).

**Вариант A** (прямой fetch к Strapi из клиента):
```typescript
const strapiUrl = 'http://127.0.0.1:1337'
const response = await $fetch(`${strapiUrl}/api/ai-assistant`, {
  params: { populate: '*' }
})
```

**Вариант B** (через собственный API endpoint):
Создать `server/api/chat-suggestions.get.ts`:
```typescript
export default defineEventHandler(async () => {
  const strapiUrl = process.env.STRAPI_URL || 'http://127.0.0.1:1337'
  const response = await $fetch(`${strapiUrl}/api/ai-assistant`, {
    params: { populate: '*' }
  })
  const data = response.data
  return {
    suggestions: data.quickSuggestions || [],
    welcomeTitle: data.welcomeTitle,
    welcomeDescription: data.welcomeDescription
  }
})
```

Я рекомендую **Вариант B** — чище, не светим Strapi URL на клиенте, можно будет кэшировать.

**В ChatAssistant.vue добавить:**
- Импорт: не нужен (auto-import для `$fetch`)
- В `onMounted`:
```typescript
const loadQuickSuggestions = async () => {
  try {
    const data = await $fetch('/api/chat-suggestions')
    quickSuggestions.value = data.suggestions.map((s: any) => s.text)
  } catch {
    quickSuggestions.value = [
      'Найди ягоды для варенья',
      'Что есть со скидкой?',
      'Подбери фрукты к чаю',
      'Покажи новинки',
      'Что посоветуешь?'
    ]
  }
}
```

**Проблема:** `quickSuggestions` сейчас `const quickSuggestions: string[] = []` — это неизменяемый примитив. Нужно заменить на `ref`:
```typescript
const quickSuggestions = ref<string[]>([])
```
