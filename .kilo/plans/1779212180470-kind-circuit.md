# План: Исправление порядка миксинов (mixin → конец селектора)

## Проблема

В 3 файлах чат-ассистента `@include adaptiveValue` расположен ДО некоторых CSS-свойств. Согласно конвенции проекта, **все `@include` должны быть строго после всех CSS-свойств** в каждом селекторе, перед вложенными блоками (`&:hover`, `&:focus`, `&--modifier`, `@include hover`, `@container` и т.д.).

**Всего: 17 нарушений**

---

## Файл 1: `ChatAssistant.vue` — 10 селекторов с нарушениями

### 1. `.chat-assistant__title` (строка 512)
```scss
// БЫЛО:
margin: 0;
@include adaptiveValue("font-size", 16, 14);  // ← mixin НЕ в конце
font-weight: 600;                               // ← CSS-свойство после mixin

// СТАЛО:
margin: 0;
font-weight: 600;
@include adaptiveValue("font-size", 16, 14);   // ← mixin после всех свойств
```

| Файл | Количество правок |
|------|------------------|
| `ChatAssistant.vue` | 10 |
