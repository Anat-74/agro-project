# Фоновое изображение на карточках товаров (план)

Статус: **не начато**, записано 16.11 по просьбе пользователя (предложение из чата 15.11).

## Зачем

Карточки выглядят «плоско»; декоративный фон даёт глубину, если не спорит с товаром.

## Откуда брать фон

| вариант | работа в админке | как выглядит |
|---|---|---|
| **A. Размытая копия `mainImage`** (blur + scale, тот же файл) | нулевая — работает сразу на всех карточках | всегда «в тему» товара, дорого смотрится; цена — один лишний слой + CSS-blur |
| **B. `backgroundImage` в Strapi** (поле у категории или у товара) | нужно заполнять | полный контроль дизайна, можно общие фоны по категориям |
| **C. Статичные паттерны/градиенты по категориям** | нет | быстро, но «беднее» — по сути замена цвета |

Рекомендация: старт с **A**, **B** — как override (если у категории задан `backgroundImage`,
используем его, иначе размытый `mainImage`).

## Загрузка и появление

- фон рендерится только когда данные карточки уже есть; сама картинка — `loading="lazy"`,
  `decoding="async"`, `fetchpriority="low"` через `UImage`/`NuxtPicture` (в проекте `@nuxt/image`);
- `IntersectionObserver`: грузим фон, когда карточка попала во вьюпорт (первый экран сразу);
- плейсхолдер — `thumbnail` из Strapi (у фонов он уже есть), без CLS;
- появление: `opacity 0 → 1` + `scale(1.04 → 1)` за 0.4–0.6 s; при `prefers-reduced-motion` — без анимации.

## Уменьшение фото товара на 30–40%

Делаем размером контейнера, а не файла: фото становится «инсетом» над фоном (отступы дают воздух).
Проверить в компакте: фон окажется под вырезом, плашкой и статусом — возможно, в углу нужно
размытие посильнее.

## Открытые вопросы

1. Источник: **A** (размытие `mainImage`) или сразу **B** (поле в Strapi)?
2. Если B — фон у **категории** или у **товара**?
3. Уменьшать фото в **обоих** режимах (обычный + компакт) или только в обычном?

## Технические заметки

- `@nuxt/image` закреплён на **2.2.1** (`package.json`), провайдер по умолчанию (IPX), домены
  Strapi прописаны в `image.domains`.
- Компакт-карточка: маска вырезает угол, плашка и статус лежат над маской — фон должен быть
  на внутреннем слое под маской, чтобы обрезаться вместе с карточкой.
- Для варианта A: фон = `mainImage` с `filter: blur(...)` + `scale(...)`, чтобы не было резких
  краёв; отдельный файл не нужен.
