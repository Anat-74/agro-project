# Правила автоматизации деплоя (Plesk + Playwright)

## 0. Жёсткие правила

- **Никаких Tab** для навигации
- **Только прямые селекторы** (`data-test-id`, `id`, `[name="..."]`)
- Если попал не на ту страницу или элемент не найден → **abort**, закрыть браузер, начать заново с логина
- Последовательность шагов строго фиксирована. Ничего не менять, не добавлять, не переставлять
- Перед каждым запуском — получить разрешение пользователя
- После каждого действия — отчёт
- **При отказе инструмента Write/Edit:** это известный временный глюк Kilo. Ошибка "Model tried to call unavailable tool 'invalid'". Повторить попытку до 3 раз с паузой. Если не сработало — сообщить пользователю

## 2. Последовательность

### Шаг 1. Логин
- URL: `https://vh324.by3020.ihb.by:8443`
- `input[name="login_name"]`, `input[name="passwd"]`
- `button:has-text("Войти")`
- `waitForLoadState`

- **ПРОВЕРКА заголовок:** `<span class="page-content-header__title">` должен содержать "vh324.by3020.ihb.by". Если нет → abort → Шаг 1

### Шаг 3. Git

### Шаг 4. Node.js build

- **ПРОВЕРКА заголовок:** `<span class="page-content-header__title">` должен содержать "Node.js на vh324.by3020.ihb.by"

- Поле ввода команды → `input.pul-input__input` (НЕ `#searchTerm`, а новый инпут в модалке)
- Ввести: `build`

## 3. Справочник селекторов Plesk (DOM)

> Если селектора нет в этом списке — **обратиться к пользователю**, не угадывать. Разрешены только прямые селекторы (`data-test-id`, `id`, `[name="..."]`, классовые уточнения).
