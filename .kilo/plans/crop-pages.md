## Цель

Отдельная страница для каждого растения (`crop`) — точки входа под запросы длинного хвоста
(«вырастить томат», «семена огурца»), естественная перелинковка и основa для ссылок-источников
в чат-ассистенте.

## Модель данных уже готова

Схема `crop` (Strapi) содержит всё необходимое, часть полей сейчас не используется как страница:

```

description (richtext, i18n), planting / seedling / fertilizing,
```

Во фронте `GardenCrop.slug` уже объявлен, но не задействован → переделки модели не требуется.

## URL и структура страниц

- **URL:** `/{locale}/posadka-i-urozhay/{cropSlug}` — вложенно под раздел.
- Так не возникает конфликта с `/{locale}/{categorySlug}` (категории каталога) и корректно
  строятся хлебные крошки.
- Структурная правка: `pages/[lang]/posadka-i-urozhay.vue` → папка
  `pages/[lang]/posadka-i-urozhay/index.vue` + `pages/[lang]/posadka-i-urozhay/[cropSlug].vue`.

## Содержимое страницы растения

1. Hero: `image`, `name`, `shortDescription`.
2. `description` (richtext) через `MDC`.
3. Калькулятор с **предвыбранной** культурой (нужен проп в общем компоненте калькулятора;
   сейчас выбирается первое растение по умолчанию).
4. Товары растения (`products`), статьи по растению (`blogs`), FAQ раздела.
5. SEO: мета из `crop.seo`; JSON-LD по существующему паттерну страницы раздела
   (WebPage + BreadcrumbList + FAQ/HowTo), `canonical` на себя.
6. Sitemap: добавить адреса растений.

## Отклонено: SSR статей в панели каталога (решение 28.09)

Включать `server: true` для `crops`/`articles` в `HamburgerGarden` **не нужно**:

- панель — оверлей-меню (`<dialog>`), её контент дублирует раздел (риск дублей);
- выбор растения — клиентское состояние: на SSR отрендерится только растение по умолчанию,
  то есть робот получит ~10 ссылок одного растения на каждой странице — это шум;
- цена: `crops` + `articles` добавляются в SSR-цепочку шапки (`AppHeader`) на всех страницах;
- SEO-связка уже покрыта: страница раздела (статьи — SSR, видимые ссылки) и блог (SSR),
  а после этой задачи — страницы растений.

Вместо этого ставка на страницы растений + sitemap.
