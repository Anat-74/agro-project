# Скидка на карточке товара — план (сессия 12.11)

Состояние: **не реализовано**, записано по просьбе пользователя, чтобы не потерять.

## 1. Старая цена + процент скидки

- В Strapi у `api::product.product` сейчас есть только `price` (decimal) и `isDiscount` (boolean).
  **Старой цены и процента в схеме нет.**
- Решение (предложение): добавить `oldPrice` — decimal, `localized: false`, необязательное.
  Процент **не хранить**: считать на фронте из `price` и `oldPrice`.
  - утилита в `frontend/shared/utils/` (автоимпорт): `discountPercent(price, oldPrice)` →
    `Math.round((oldPrice - price) / oldPrice * 100)`, ограничение 1..99;
  - показывать скидку только если `isDiscount === true && oldPrice > price`.
- Почему так, а не «только процент»: старую цену нельзя будет показать (перечёркнутую),
  а процент, введённый руками, легко расходится с ценами. Одна величина (oldPrice) — один источник.
- Strapi v5: скалярные поля приходят по умолчанию (без `populate`), в списке товаров
  `populate` нужен только для `image` — менять запросы не нужно.
- Тип: `frontend/shared/types/product.ts` → `oldPrice?: number | null`.

## 2. Разметка карточки (compact)

- Старая цена: `<del>` (перечёркнутая) + бейдж «−N%». Показывать только для скидочных товаров.
  Место — в нижней полосе рядом с ценой (обсудить: под ценой или справа).
- Иконка акции (`mdi:discount`, класс `product-card__discount`): сейчас лежит в `__top-items`
  (внутри маски) и попадает в вырез под статус — её обрезает. Перенести в нижнюю полосу,
  **перед иконкой рубля**, размер уменьшить в 2 раза.

## 3. Порядок работ

1. Схема Strapi: `oldPrice` (+ перезапуск Strapi; проверить запись/чтение через API).
2. Тип + утилита процента (+ юнит-тест vitest).
3. Разметка/стили: `<del>`, бейдж, перенос иконки акции.
4. Проверка на 390 (кроп карточки), затем остальные локали (ru/be) и обычный (не компакт) режим.

## 4. Открытые вопросы к пользователю

- Показывать ли старую цену вместе с процентом, или только процент?
- Формат бейджа: «−15%» или «Скидка 15%»?
- Где именно в нижней полосе: слева от цены, под ценой, справа?

## 5. Согласованный контракт (12.11)

- Strapi: `price` (decimal, базовая) + `discountPercent` (integer 0..99, не локализуется) + `isDiscount`.
  Скидка действует только при `isDiscount === true && discountPercent > 0`.
- Итоговая цена считается **только** утилитой `finalPrice()` в `frontend/shared/utils/discount.ts`
  (округление до копеек). Там же `discountPercent()` и `hasDiscount()`.
- На карточке: сверху итоговая цена, под ней старая — перечёркнутая (`<del>`/`<s>`), шрифт в 2–3 раза
  мельче + бейдж «−N%».
- Иконка акции `mdi:discount` перенесена в нижнюю полосу **перед иконкой рубля**, размер вдвое меньше.
