## Цель
Один смысловой раздел для выращивания: **семена + рассада + удобрения**, связанные растением
и **калькулятором посадок**. Раздел = **категория каталога + хаб-страница**.

## Решения (22.09)

1. **Статья на телефоне — модальным окном**, а не переходом на страницу. Страница статьи остаётся
   для десктопа, поисковых систем и прямых ссылок.
2. **Порог:** ≤ 1024 точек — модальное окно; больше — переход на страницу (как в корзине).
3. **Кнопка «Рассчитать посадку» внутри модального окна статьи:**
   - открыли из панели «Посадка» → **не показывать** (человек уже в калькуляторе);
   - открыли со страницы «Блог» или со страницы раздела → **показывать**.
4. **SEO-связка статьи** — по образцу карточки товара (`DiscountProduct.vue`):
   настоящая ссылка на страницу (индексируется) + микроразметка статьи + скрытый текст
   через `.visually-hidden` + **общий ключ кэша** со страницей статьи.
5. **Страница раздела:** добавить скрытый SEO-блок — растения и товары раздела настоящими ссылками
   и названия режимов расчёта. Микроразметку **не делаем**: у раздела нет отдельного объекта, а его
   разметка уже отдаётся через JSON-LD.

и в списке блога.

**Шаг 2 — скрытый SEO-блок на странице раздела.**
Растения и товары раздела настоящими ссылками, названия режимов расчёта.

**Шаг 3 — правки корзины (22.09, ждут решений):**
- кнопка добавления — с иконкой корзины, а количество добавленного показывать **над кнопкой**
  через позиционирование (без влияния на соседние элементы и без сдвига контента);
- сама корзина (индикатор) — **фиксированная**, чтобы не дёргать контент и быть всегда на виду.

**Шаг 4 — втиснутый крестик и плюс (23.09, спека; НЕ реализовано — ждём скриншот).**

Эталон «втиснения» в проекте (копировать значения, не изобретать свои):

- рамка-разделитель colorMode ↔ langSwitcher (`BannerLayouts.vue`, строки 60–63):
  ```scss
  border: toRem(1) solid rgba(0, 0, 0, 0.25);
  box-shadow: 0 toRem(1) 0 rgba(255, 255, 255, 0.4);   // светлый блик ПОД линией
  ```
- разделитель секций в фильтрах (`ShowShopFilter.vue`, строки 583–586): то же самое —
  тёмная линия + светлый блик снизу.

Суть эффекта: **тонкая линия (1–2px) тёмного полупрозрачного цвета + светлый блик на 1px ниже**.
Это «канавка». Никаких толстых полос и inset-теней на них.

**Кнопка закрытия панели (`ShowHamburger`, крестик в шапке):**
- фон — **прозрачный**, как у поля ввода (`background-color: transparent`);
- рамка — как у поля поиска: `toRem(2) solid var(--primary-color)` (проверено замером:
  у поля `2px rgb(126, 182, 147)`), плюс к рамке светлый блик снизу из эталона;
- скругление 10px по всем четырём углам;
- крестик — **цветом рамки** (`var(--primary-color)`), полосы тонкие, с тем же приёмом
  (светлый блик на 1px ниже), т.е. выглядит врезанным в поверхность.
  ⚠️ По скриншоту 23.09: крестик **не зелёный и без эффекта** — нужно и цвет рамки, и «канавку».
- Адрес правки: `ShowHamburger.vue`, блок `&__close` (сейчас 696–715). Не забыть `:deep(span)` —
  средняя полоса рисуется внутри `UButton`, обычный scoped-селектор до неё не достаёт.

**Кнопка добавления в корзину (`HamburgerGarden`, строка товара):**
- изначально (товара нет в корзине) — **только иконка корзины, без плюса**;
- плюс появляется **только после добавления** товара (`v-if="cartQtyFor(...) > 0"` — сейчас
  условие потеряно, плюс виден всегда — это ошибка);
- плюс — **по центру кнопки** (не в углу иконки);
- плюс тонкий (полосы 1–2px), цвет тёмный полупрозрачный, со светлым бликом снизу — тот же эталон;
  за счёт тонких полос иконка корзины остаётся читаемой;
- счётчик количества — над кнопкой **справа** (уже сделано);
- кнопка — обычная (светлая, рамка), не «втиснутая».

**Открытые вопросы к спеке (нужен скриншот текущего состояния + эталона):**
1. Цвет рамки кнопки закрытия: зелёный как у поля поиска — подтвердить.
2. Плюс по центру поверх корзины: устраивает ли, что тонкие полосы плюса пересекают иконку
   (корзина остаётся видна), или плюс должен быть рядом с иконкой?

**Что видно на скриншоте 23.09 (подтверждает дефекты):** у кнопки закрытия светлый фон
(нужен прозрачный) и зелёный крестик (это верно); у кнопки добавления плюс показан, хотя товар
в корзине отсутствует, плюс стоит в углу иконки (нужен по центру), эффекта вдавливания не видно.

**Шаг 5 — рамка правой группы в шапке (23.09, спека; НЕ реализовано).**

Задача: правой группе иконок в шапке главной (`.header__container-top` → поиск, AI, корзина,
профиль; `AppHeader.vue`, строки 121–124) дать такой же эффект рамки, как у блока
langSwitcher/colorMode в баннере.

Эталон (`BannerLayouts.vue`, строки 59–64):
```scss
background-color: rgba(255, 255, 255, 0.15);   // полупрозрачный светлый фон
border: toRem(1) solid rgba(0, 0, 0, 0.25);     // тёмная линия
box-shadow: 0 toRem(1) 0 rgba(255, 255, 255, 0.4);  // белый блик снизу
border-radius: toRem(6);
padding: toRem(4);
```

Уточнить перед реализацией:
1. Рамка вокруг **всей группы иконок** (одна общая рамка, как у langSwitcher) или у каждой
   иконки отдельно?
2. Нужен ли фон `rgba(255,255,255,0.15)` и внутренние отступы, или только рамка со бликом?

**Замечено попутно (тоже требует решения):**
- у иконки корзины в шапке показывается красный счётчик «0», когда корзина пуста — логичнее
  скрывать счётчик при нуле;
- подпись «Что сажаем?» на слайде «Посадка» плохо читается поверх размытого цветного фона;
- последний вопрос FAQ на слайде упирается в точки-пагинацию.

**Шаг 6 — калькулятор: подзаголовок, поле площади, единицы измерения (23.09, спека).**

1. **Подзаголовок над «Площадь»** — чтобы было понятно, что блок относится к калькулятору
   (варианты текста: «Калькулятор расчёта», «Расчёт посадок» — уточнить). Новый ключ в `locales/garden.ts`.
2. **Поле площади перевести на компонент `UInput`.** Сейчас это сырой `<input type="number">`
   (`HamburgerGarden.vue`, строки 444–458) — по стилю проекта поля должны быть через `UInput`
   (`type="number"`, `min`, `step`, `aria-label`; единица измерения — рядом или слотом).
3. **Удобный ввод значения.** Сейчас при клике курсор встаёт после цифры и её нужно стирать.
   Предлагаю при фокусе **выделять значение целиком** — пользователь сразу печатает нужное число.
   Альтернатива: очищать поле при фокусе и возвращать значение по умолчанию, если ничего не ввели
   (нужно выбрать вариант).
4. **Единицы площади: м² и сотки** (1 сотка = 100 м²). В расчёте площадь всегда в м²,
   в интерфейсе показываем в выбранной единице. Нужен переключатель (по образцу табов режимов)
   и ключи локализации (`areaUnitSqm`, `areaUnitSotka`).
