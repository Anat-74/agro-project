# План: Агро-раздел «Всё для посадки и урожая» + калькулятор

> **Режим:** удалённая работа. Ни шага без одобрения; после каждого шага — отчёт.
> **Реализация только в не пиковые часы** (7–9 и 13–4 МСК). В пиковые (9–13 и 4–7 МСК) код не трогаем —
> только анализ, обсуждение и записи в план.
> Обновлён: 2026-09-25. Связанное: `show-hamburger-plan.md` (панель/табы/поиск),
> `1778783966963-style-guide.md` (стиль), `frontend-backend-rules.md` (данные).

## Цель
Один смысловой раздел для выращивания: **семена + рассада + удобрения**, связанные растением
и **калькулятором посадок**. Раздел = **категория каталога + хаб-страница**.

## Конвенции (решения 22.09, действуют)

- **Статьи на телефоне — модальным окном**, не переходом; порог — ≤ 1024, выше — страница.
  Ссылка остаётся настоящей (индексируется), SEO-связка — как у карточки товара (`DiscountProduct.vue`):
  микроразметка статьи + скрытый текст через `.visually-hidden` + общий ключ кэша со страницей статьи.
- **Кнопка «Рассчитать посадку»** внутри модалки статьи: открыли из панели «Посадка» — не показывать,
  из блога или страницы раздела — показывать.
- **Скрытый SEO-блок страницы раздела:** растения и товары раздела настоящими ссылками + названия
  режимов расчёта. Микроразметку не делаем — у раздела нет отдельного объекта, JSON-LD уже отдаётся.

## Решения (25.09) — панель «Посадка»

Утверждено 25.09. **Реализуем по одному пункту:** сделал пункт → отчёт → проверка пользователем →
следующий пункт (не всё одним заходом). Только в непиковое окно:

1. **Единицы площади** (`&__unit` в `HamburgerGarden.vue`):
   - убрать `text-transform: uppercase` у кнопок-единиц;
   - значения задать прямо в локалях (`frontend/app/locales/garden.ts`, ru + be):
     `areaUnitSotkaTab` → «Сотки» / «Соткі», `areaUnitSqm` → «М²» (верхний регистр остаётся,
     но теперь значением, а не CSS);
   - шрифт обеих кнопок-единиц: 13px → **15px** (+2px).
2. **Блок «Калькулятор расчёта» → слайдер** по образцу слайдера в `ShowHamburger`:
   - **табы** — существующие кнопки режимов «Семена | Рассада | Удобрение» (уже `role="tablist"`),
     стили не меняем;
   - **слайды** — по одному на режим: строки результата, «упаковки» и доп. строки `modeInfo`
     (то, что сейчас показывается по `v-if` на `mode`);
   - **точки пагинации внизу блока по центру** — как в ShowHamburger, но **без подложки** (только точки);
   - механика — `USlider` (клик по табам/точкам + свайп, `scroll-snap`); стили существующих элементов
     не меняем, добавляем только стили точек.
   - **«Площадь»** (подпись + единицы + поле ввода) — общая **над слайдером**: значение одно,
     от режима не зависит (сейчас так же).
   - **«Товары для растения»** ниже — фильтруются по активному табу/слайду (как сейчас по режиму).
   - Подпись у поля («5 соток») — **не меняем** (форма для значения).
   - ⚠️ **Проверяет пользователь после реализации:** вложенный слайдер внутри горизонтального слайда
     панели — риск конфликта жестов; если конфликтует, оставить только клики по табам/точкам.
3. **Блок «Товары для растения» — группы на `UAccordion`** (утверждено 25.09):
   - группы «Семена / Рассада / Удобрение» переводим с обычного `<h4>` + список на **`UAccordion`**
     (тот же подход, что в «Частых вопросах»): в слот `#header` — иконка группы (`group.icon`) + название
     + **пунктирная линия-лидер** + штатный шеврон аккордеона;
   - **лидер:** пустой флекс-элемент `flex: 1`, высота 0, `border-bottom: 1px dashed var(--border-color)`,
     `align-self: center`; всё содержимое summary центрируется по вертикали (`align-items: center`).
     Пунктир — **только для групп товаров** (визуально разграничивает категории);
   - глобальные стили summary (фон/паддинги/оутлайн) нейтрализуем, чтобы сохранить текущий вид группы;
   - аккордеоны **независимые** (`name` не задаём);
   - открыты **по умолчанию**; в теле — **2 товара** (`slice(0, 2)`), ниже шеврон «показать все»
     (иконка + локализованный `aria-label`), показываем только если товаров больше 2; клик раскрывает
     весь список, повторный — сворачивает;
   - обрезка — **одинаково** в панели и на странице раздела; данные не меняем (`purposeGroups`
     уже отдаёт массив товаров на группу);
   - **кнопку корзины переносим** из «шапки» слайда «Посадка» (`ShowHamburger.vue`, `CartPanelButton`)
     в строку заголовка этого блока — **справа**, по центру строки и по правому краю (на одну вертикаль
     с шевронами групп), **без пунктира**; на странице раздела (`/posadka-i-urozhay`) кнопка не появляется
     (слот в заголовке не используется);
   - **кнопку уменьшить на 3px** — габарит и иконку вместе;
   - **попутно:** у `&__question-icon` (иконка заголовка раздела, например «Товары для растения»)
     починить обрезку сверху — `overflow: visible` + `display: block`; применить ко всем
     заголовкам раздела.

4. **Пагинация панели (точки внизу):**
   - вертикальный отступ до кромки панели — **на 3px меньше** (сейчас `--axis-bottom: 8px` → 5px);
   - **светлый фон-плашка вокруг точек — уже**: уменьшить её паддинги/высоту (замерить и подобрать,
     чтобы плашка не «выпирала» вокруг точек);
   - ⚠️ точки, кнопка телефона и кнопка соцсетей стоят на **одной оси** от общих переменных
     (`--axis-h`, `--axis-bottom`) — правки применять ко всей оси, иначе разъедутся центры;
   - если сделать плашку уже проблематично (поедет выравнивание оси или вид) — **оставляем как есть**.

5. **Модальное окно статьи — `min-height`:** окно открывается раньше, чем приходят данные, и после
   загрузки скачком увеличивается по высоте («дёргание»). Задать `min-height` (по высоте скелетона /
   ожидаемого контента), чтобы окно сразу открывалось нужного размера и не прыгало.

`fertilizing`, `sowing`, `seo`, `category`, связи `products` и `blogs`, `isActive`.

(`mainImage` — нелокализуемое, 24.09).

для текущих проверок допустимы примерные значения.
