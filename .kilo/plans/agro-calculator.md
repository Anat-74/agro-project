## Цель
Один смысловой раздел для выращивания: **семена + рассада + удобрения**, связанные растением
и **калькулятором посадок**. Раздел = **категория каталога + хаб-страница**.

## Решения (22.09)

1. **Статья на телефоне — модальным окном**, а не переходом на страницу. Страница статьи остаётся
   для десктопа, поисковых систем и прямых ссылок.
2. **Порог:** ≤ 1024 точек — модальное окно; больше — переход на страницу (как в корзине).
3. **Кнопка «Рассчитать посадку» внутри модального окна статьи:**
   - открыли из панели «Посадка» → **не показывать** (человек уже в калькуляторе);
   - открыли со страницы «Блог» или со страницы раздела → **показывать**.
4. **SEO-связка статьи** — по образцу карточки товара (`DiscountProduct.vue`):
   настоящая ссылка на страницу (индексируется) + микроразметка статьи + скрытый текст
   через `.visually-hidden` + **общий ключ кэша** со страницей статьи.
5. **Страница раздела:** добавить скрытый SEO-блок — растения и товары раздела настоящими ссылками
   и названия режимов расчёта. Микроразметку **не делаем**: у раздела нет отдельного объекта, а его
   разметка уже отдаётся через JSON-LD.
