## Текущее состояние (mobile, фильтр ОТКРЫТ)

- **Панель фильтров** — `position: fixed` (независима от скролла карточек):
  - `top: var(--crumb-h)` (сразу под липкими крошками), `left: toRem(12)`, `width: var(--filter-drawer-w)`
    (163px, `−2px`), `height: calc(100dvh − var(--crumb-h) − toRem(4))` — **постоянная** (без ресайза/дёрганья),
    свой внутренний скролл (у диалога `overflow: hidden auto`), фон `var(--bg)`.
  - **Шапка панели** (`.shop-filters__header`): крестик **слева**, селект сортировки **справа** — **не sticky**
    (скроллится с содержимым). На desktop скрыта (там сортировка/кнопка в тулбаре).
- **Шапка сайта** — `display: none` (AppHeader `_filter-open`, mobile): «дыры» нет, сдвигов не требуется.
- **Крошки** (шапка страницы `.products-page__header`) — `position: sticky; top: 0`, `margin-block-end: 0`.
- **Тулбар** страницы (`.products-page__container-top`) — `display: none` (его контролы — в шапке панели).
- **Товары** — 1 колонка, сдвинуты вправо: `padding-inline-start: calc(toRem(12) + var(--filter-drawer-w) + toRem(10))`;
  у списка `padding-block-end: 0` (резерв под «плавающую» пагинацию не нужен), `overflow-x: clip`.
- **Пагинация** — absolute в `container-body`; при открытом `bottom: toRem(-53)` → её низ **совпадает с низом
  панели** (`791 = 791`, diff 0). Список карточек сохраняет базовый `padding-block-end: 64px` (резерв),
  поэтому зазор «последняя карточка → пагинация» = **74px**.

  > Геометрия: панель `fixed` (вьюпортная) — низ = `100dvh − крошки − 9`; товары — в потоке и в самом низу
  > страницы заканчиваются на `738` (карточка `674` + резерв `64`) → не достигают низа панели. Пагинация
  > сдвигом `bottom: -53` «перекрывает» эту разницу и встаёт вровень с панелью. Карточки вровень быть не
  > могут, пока панель вьюпортная, а товары — в документе.

  - **10.10:** пробовали убрать резерв (`padding-block-end: 0`) ради зазора 10px — но тогда пагинация ушла
    на 64px выше низа панели, и **пользователь предпочёл выравнивание по панели** → резерв возвращён (зазор 74).
- **Декоративный разделитель (12.10):** в зоне резерва между последней карточкой и пагинацией —
  линия + иконка-росток (`mdi:sprout`), по ширине товарной колонки, **смещён ниже центра** зазора.
  - Разметка: `<li class="products-page__divider" aria-hidden="true">` внутри `ul` (декор; `v-if="pageCount > 1"`).
  - Стили: `.products-page__card-list { position: relative }`; `&__divider { display: none }` (десктоп/закрыт);
    на mobile при `_filter-open` — `display: flex; align-items: center; position: absolute;
    inset-inline: 0; bottom: toRem(-11); height: toRem(73); padding-inline: toRem(10)` (бокс = зазор
    «низ последней карточки → верх пагинации», сдвинут на 2px ниже центра; `padding-inline` — отступ
    от краёв колонки, чтобы были видны закруглённые концы). Иконка `--green-color`, `font-size: toRem(43)`.
    Линии `::before/::after`: `height: toRem(2)`, `border-radius: toRem(25)`, «вдавленный» эффект —
    `background: rgba(0,0,0,0.28)` + `box-shadow: 0 toRem(1) 0 rgba(255,255,255,0.7)`. `pointer-events: none`.
  - ⚠️ **Грабли (12.10):** размер иконки задавать НА САМОМ `svg` (`svg { font-size: toRem(30) }`), а НЕ на обёртке:
    глобальное `.iconify { font-size: toRem(25) }` (`base/_utils.scss`) задаёт font-size svg, а `width/height` svg = `1em`
    = его собственный font-size → `font-size` на обёртке иконку НЕ менял (прошлые +30%/+20% были no-op, иконка была 25px).
  - **Ревью 12.10:** иконка реально 25px (`.iconify`) → 30 → 35 → **40px** (+5px, через `svg`); разделитель
    центрируется боксом (`bottom: -9; height: 73`), а не подгонкой `bottom`.
- **Нижний запас под пагинацией (mobile, фильтр открыт, 12.10):** пагинация `absolute` (`bottom: -53`)
  переполняет `container-body` на 53px и является самым низким элементом документа → без запаса
  прилипала к самому низу экрана (отступа не было ни на одной странице; на 1-й «отступ» был виден

  (падинг секции > 53px) → под пагинацией ровно 12px. Проверено инъекцией CSS на проде (390×800):
  `pagBottom 800→788`, `gapViewport 0→12`, зазор разделитель→пагинация без изменений (18px).
- **Верхний отступ карточек (mobile, фильтр открыт, 12.10):** первая карточка прилипала к крошкам
  (`gapCrumbCard 0`) → `.products-page_filter-open .products-page__card-list { padding-block-start: toRem(12) }`.
- **Зазор панель→карточки = 2px (12.10, финал):** ширина панели на mobile
  `--filter-panel-w: calc(var(--filter-drawer-w) − #{toRem(2)})` (163px вместо 165); сдвиг колонки
  `calc(toRem(12) + var(--filter-drawer-w))` (без доп. слагаемого) → карточки начинаются на `177`,

  - ⚠️ **Грабли (12.10):** в SCSS внутри **custom-property** (`--x: …`) функции НЕ вычисляются — нужна

- **Нижний отступ баннера в панели фильтров (mobile, 12.10):** баннер «Скидка 79%» — последний блок

  исключён из `body:has(…) overflow: hidden` (лок оставлен для корзины/чата/гамбургера).
