# Ассистент: веб-поиск и чтение страниц (DeepSeek Search / Fetch)

Статус: **идея, не подключено** (зафиксировано 27.10.2026).

## Что даёт
- `POST /v1/tools/search` — веб-поиск: `title`, `url`, `snippet`, `summary` (600–800 симв. «для модели»),
  `date`, `authority` (0–4), `rerank_score` (0–3).
- `POST /v1/tools/fetch` — страница → Markdown (полный текст).
- Ассистент отвечает по **свежим источникам**, а не только по Strapi.

## Зачем агро-магазину
- «Когда сажать огурцы в Беларуси», «чем обработать фитофтору», «сорта сливы для средней полосы»;
- «рецепт заготовки из алычи», «цены на рассаду по региону».

## Реализация (когда решим)
- Два tool-call'а в `frontend/server/api/chat-assistant.post.ts` (схема tool-calls уже есть,
  `DEEPSEEK_API_KEY` уже используется).
- Фильтр качества: `authority >= 3`, `rerank_score >= 1.5`; 1–2 поиска на вопрос; кэш результатов.
- В ответе — **ссылки на источники** (иначе доверие падает).

## Стоимость и лимиты
- 5 ¥ за 1000 **успешных** запросов (≈0.7$), не по токенам; пустые/ошибочные не тарифицируются.
- Search 100 QPS, Fetch 25 QPS (на аккаунт).
- Латентность +1–2 с на поиск → нужен индикатор/стриминг.

## Риски
- Мусор/не та тема → фильтр по `authority`, `site:`, тематике (агро).
- Обязательные ссылки-источники в ответе.
