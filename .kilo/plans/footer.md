# План: компактный футер

> Решения 06.10.2026. Реализация — **в непиковые часы**. Деплой API — по команде
> (перезапуск приложения делает пользователь).

## Цель

Футер должен занимать **значительно меньше места**, чем сейчас, но сохранить нужную информацию.

## Текущее состояние и дублирование

`AppFooter` содержит: логотип, соцсети, «Компания» (название, УНП, часы, юр.адрес, телефоны, email),
`NavigationFooter` (О нас / Услуги / Блог / Контакты — захардкожены), «Банк. реквизиты», copyright,
`ScrollToTop`.

Дубли шапки: навигация (`global.header.navigation` → `BaseNavigation`), телефоны/email (поповер
контактов). Локализация (`be`) — отдельная задача, здесь только `ru`.

## Решения (06.10)

- **Компания** и **Банковские реквизиты** → `UAccordion`, **оба свёрнуты** по умолчанию.
  - «Компания»: название, УНП, часы работы, юр.адрес, **телефоны, email**.
  - «Банковские реквизиты»: банк, адрес, счёт, SWIFT.
- **Логотип** (`ULogo`), **соцсети**, **copyright** — остаются.
- **Убрать** `NavigationFooter` (полный дубль меню шапки).
- **Фоновое изображение** — на всю площадь футера, **общее для всех страниц**:
  - источник — Strapi, компонент `background.background-image` (как у крошек):
    `baseBgImageWebp` (1x) + `retinaBgImageAvif` (2x);
  - рендер — существующим **`UBackground`** (`variant="clean"`, `size-mode="cover"`,
    `bg-position="center"`);
  - **затемнение — в стилях** (полупрозрачный тёмный слой над фоном, под контентом) — для контраста (AA).
- **`ScrollToTop`** — оставляем как есть: `v-show` + fixed, на поток и высоту футера не влияет.

## Изменения в Strapi

- В компонент **`layout.footer`** добавить поле `background` (тип — компонент
  `background.background-image`).
- Остальные данные уже есть: `global.footer` (companyName/taxId/workingHours/legalAdress/copyright),
  `global.legal` (`legal.bank-details`), `global.phones`, `global.email`, `global.socials`.
- Заполнить `background` на проде (`ru`) — та же картинка, что у крошек.
- Поле `logo` в `layout.footer` не используем — логотип берём общий `ULogo`.
- **Деплой API + перезапуск** (делает пользователь).

## Изменения во фронте

`app/components/AppFooter.vue`:
- обёртка `position: relative`; фон — `UBackground` **sibling-ом** (как в `UBreadcrumbs`),
  контенту — `position: relative; z-index: 1` (скоуп-правило `.app-bg ~ *` из `UBreadcrumbs`
  в `AppFooter` не действует);
- слой затемнения (`::after`) между фоном и контентом;
- заменить блоки «Компания»/«Реквизиты» на **`UAccordion`** (слот `header` + контент, `open=false`);
- удалить `NavigationFooter`;
- оставить `ULogo`, `USocials`, copyright, `ScrollToTop`;
- компактная сетка (лого/соцсети → аккордеоны → copyright) и уменьшенные отступы/высота.

Типы: `FooterData` (глобальные типы) расширить полем `background`
(`background.background-image`).
