# Рефакторинг шапки сайта (header)

## 1. Strapi — структура данных

### 1.1 Компонент `header.header` (в Global)

Компонент с полями:

| Поле | Тип | Назначение |
|---|---|---|
| `bannerText` | string (localized) | Текст баннера |
| `navigation` | dynamiczone (components: `nav.link`) | Пункты навигации, порядок — перетаскиванием |

### 1.2 Компонент `nav.link`

| Поле | Тип | Назначение |
|---|---|---|
| `label` | string (localized) | Текст ссылки |
| `url` | string | Путь (напр. `/about`, `/services`) |

Dynamic Zone позволяет менять порядок элементов перетаскиванием в Strapi UI, а в будущем — добавлять новые типы компонентов (например, разделитель или группу ссылок).

### 1.3 Страницы в Strapi

| Тип | Content Type | Сейчас | Статус |
|---|---|---|---|
| О нас | singleType `about-page` | `about.vue` (хардкод) | ➕ создать |
| Услуги | singleType `services-page` | `services.vue` (хардкод) | ➕ создать |
| Контакты | singleType `contacts-page` | `contacts.vue` (хардкод) | ➕ создать |
| Блог | collectionType `blog` | `blog.vue` (пусто) | ➕ создать |
| Новости | collectionType `news` | нет | ➕ создать |
| Главная | singleType `home-page` | `index.vue` ← Strapi | ✅ существует |

Каждая запись в Strapi содержит свой набор полей + SEO-компонент (`seo.seo`: `metaTitle`, `metaDescription`, `structuredData`).

## 2. Banner — анимация

### 2.1 Проблема
Текст "Store Location: Kolasa - 34, Minsk, Belarus" хардкодом.

### 2.2 Решение
- `BannerLayouts` принимает `bannerText` через props из `global.header.bannerText`
- Создать `UMarqueeText` — переиспользуемый компонент бегущей строки

### 2.3 Компонент `UMarqueeText`

Универсальный компонент для любой бегущей строки (баннер, скидочная строка в SaleProductsSection).

**Props:**
- `text` — строка
- `speed` — скорость анимации (сек, по умолчанию 9)

```vue
<UMarqueeText :text="global.header.bannerText" :speed="12" />
<UMarqueeText :text="saleText" :speed="9" />
```

Внутри — дублирование текста через два `<span>` + `@keyframes scroll`. Единый стиль анимации во всём проекте, без дублирования CSS.

## 3. ColorMode — редизайн

### 3.1 Проблема
3 отдельные кнопки (light/dark/custom) + ползунок яркости. На мобилке много места.

### 3.2 Решение
- Один ползунок (`<input type="range">`) для яркости
- Круглая точка заменена на **иконку текущей темы** (sun/moon/coffee)
- Ползунок имеет 4 вертикальные риски (делят на 5 сегментов)
- При клике на иконку — `div` с `position: absolute`, выбор темы

```
[ 🌙 | |  |  |  |███████| ]
       ↑  ↑  ↑  ↑  — 4 риски
```

Попап выбора:
```
┌─────────────┐
│ ☀️ Светлая  │
│ 🌙 Тёмная   │
│ ☕ Кастом    │
└─────────────┘
```

## 4. Sticky-элементы

- `header__container-top` — `position: sticky; top: 0; z-index: 2`
- `header__container-bottom` — `position: sticky; top: 0; z-index: 1`

При скролле вниз `header__container-bottom` уезжает вверх под верхний блок (`translateY(-100%)`). При скролле вверх — появляется обратно. Отслеживание через `window.scrollY` + `requestAnimationFrame`.

## 5. Расположение элементов в шапке

### Desktop

```
Top row:    [Logo] [🔍Search] [💬Chat] [🛒Cart] [👤Profile]
Bottom row: [AnimateTitle] [⏷Ещё▸] [Блог] [☰Каталог]
```

- Поиск — миниатюрный (только "Поиск...", вводимый текст дублируется в overlay)
- Чат — маленькая иконка (не плавающая кнопка), между поиском и корзиной
- `⏷Ещё▸` — `<details>` выпадающий список: О нас, Услуги, Контакты, Новости
- Блог — отдельная видимая ссылка (для SEO)
- Каталог (ShowHamburger) — на своём месте

### Mobile (<768px)

```
Top row:    [Logo] [🔍Search] [💬Chat] [🛒Cart]
Bottom row: [AnimateTitle] [⏷Ещё▸] [Блог] [☰Каталог]
```

Профиль на мобилке можно скрыть или разместить внутри `⏷Ещё▸`. Приоритет — мобильная версия.

## 6. Поиск — overlay по центру экрана

### 6.1 Проблема
Результаты поиска (`header__product-filter-card`) висят в header — на мобилке накладываются на контент, на десктопе — далеко от поля ввода.

### 6.2 Решение
- Поле ввода в топе — минимального размера
- Вводимый текст дублируется **по центру viewport** над результатами
- Результаты — `position: fixed` оверлей с затемнением фона

```
[ 🔍 |__________________| ]
       ↑ поле ввода (мини)

    ┌──────────────────────┐
    │   Сообщение: яблоки   │   ← крупно
    │                      │
    │ ┌────────────────┐   │
    │ │ Яблоко Каштель  │   │
    │ │ 8.04 руб        │   │
    │ └────────────────┘   │
    └──────────────────────┘
    ↑ position: fixed, центр экрана
```

- Компонент отображается, когда `searchStore.hasSearched === true`
- Размещается в `app.vue` (вне header)

## 7. Позиционирование на мобилке (баг)

### Проблема
`header__search` и `header__profile` в одной ячейке `grid-column: 2/3; grid-row: 1/2`.

### Решение
Профиль переносится в bottom, чат добавляется в топ. Конфликт ячейки исчезает.
